# Employee CRUD Component for SharePoint

This Angular component provides full CRUD (Create, Read, Update, Delete) operations for managing employees in a SharePoint list called "employee".

## Features

### ✅ Complete CRUD Operations
- **Create**: Add new employees with full validation
- **Read**: Display all employees in a responsive table
- **Update**: Edit existing employee information
- **Delete**: Remove employees with confirmation

### ✅ Advanced Functionality
- **Search**: Real-time search across all employee fields
- **Validation**: Comprehensive form validation with error messages
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Loading States**: User-friendly loading indicators
- **Error Handling**: Graceful error handling with user feedback

### ✅ SharePoint Integration
- Uses SharePoint REST API for all operations
- Proper headers and authentication handling
- OData queries for efficient data retrieval
- Support for filtering and searching

## Employee Data Structure

The component manages the following employee fields:

```typescript
{
  Id?: number;              // Auto-generated by SharePoint
  Title: string;            // Full name/display name (required)
  FirstName: string;        // First name (required)
  LastName: string;         // Last name (required)
  Email: string;            // Email address (required, validated)
  Department: string;       // Department (required, dropdown)
  Position: string;         // Job position (required)
  Phone?: string;           // Phone number (optional, validated)
  HireDate: Date;          // Hire date (required)
  Salary?: number;         // Salary (optional)
  Status: 'Active' | 'Inactive'; // Employee status (required)
  Created?: Date;          // Auto-generated by SharePoint
  Modified?: Date;         // Auto-generated by SharePoint
}
```

## Setup Instructions

### 1. SharePoint List Configuration

Create a SharePoint list named "employee" with the following columns:

| Column Name | Type | Required | Settings |
|-------------|------|----------|----------|
| Title | Single line of text | Yes | Default title column |
| FirstName | Single line of text | Yes | Max 50 characters |
| LastName | Single line of text | Yes | Max 50 characters |
| Email | Single line of text | Yes | Email validation |
| Department | Choice | Yes | HR, IT, Finance, Marketing, Operations, Sales |
| Position | Single line of text | Yes | Max 100 characters |
| Phone | Single line of text | No | Phone number format |
| HireDate | Date and Time | Yes | Date only |
| Salary | Number | No | Currency format |
| Status | Choice | Yes | Active, Inactive |

### 2. SharePoint Configuration

Update the SharePoint service configuration:

```typescript
// In src/app/services/sharepoint.service.ts
private siteUrl = 'https://yourtenant.sharepoint.com/sites/yoursite';
private listName = 'employee';
```

Replace with your actual:
- `yourtenant`: Your SharePoint tenant name
- `yoursite`: Your SharePoint site name

### 3. Authentication

For production deployment, ensure proper authentication:

1. **SharePoint Framework (SPFx)**: Use SPFx context for authentication
2. **Add-in Model**: Configure app permissions
3. **Modern Authentication**: Use MSAL for OAuth2

### 4. CORS Configuration

If running from external domain, configure CORS in SharePoint or use a proxy.

## API Operations

### Get All Employees
```
GET /_api/web/lists/getbytitle('employee')/items
```

### Get Employee by ID
```
GET /_api/web/lists/getbytitle('employee')/items(ID)
```

### Create Employee
```
POST /_api/web/lists/getbytitle('employee')/items
Content-Type: application/json;odata=verbose
```

### Update Employee
```
POST /_api/web/lists/getbytitle('employee')/items(ID)
X-HTTP-Method: MERGE
IF-MATCH: *
```

### Delete Employee
```
POST /_api/web/lists/getbytitle('employee')/items(ID)
X-HTTP-Method: DELETE
IF-MATCH: *
```

### Search Employees
```
GET /_api/web/lists/getbytitle('employee')/items?$filter=substringof('searchterm',Title)
```

## Troubleshooting

### Common Issues

1. **"Employee list not found"**
   - Verify list name matches exactly
   - Check list permissions

2. **"Access denied"**
   - Verify user has contribute permissions
   - Check authentication configuration

3. **"Invalid column name"**
   - Verify all columns exist in SharePoint list
   - Check column internal names

4. **Form not submitting**
   - Check form validation errors
   - Verify required fields are filled
